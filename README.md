# ARTi Platform – Generative Services

Серверная часть для генерации изображений и 3D‑моделей с использованием искусственного интеллекта.  
Компонент экосистемы **ARTi Platform** – модуль **Forge**, отвечающий за создание визуального контента.

## Возможности

- **Текст → изображение** – генерация изображения по текстовому описанию с помощью диффузионных моделей (например, Stable Diffusion, PixArt‑Sigma, HunyuanDiT).
- **Изображение → 3D** – создание трёхмерной модели с текстурами на основе входного изображения.
- **Текст → 3D** – сквозной пайплайн: текст → изображение → 3D‑модель.
- **Управление ресурсами** – автоматическая загрузка/выгрузка моделей в зависимости от доступной видеопамяти и текущих задач.
- **Гибкая архитектура** – все компоненты построены на абстрактных интерфейсах; замена модели или способа исполнения не требует переписывания кода.
- **Масштабирование** – поддерживаются локальный монолитный режим, набор микросервисов на одной машине и работа через удалённые сервисы.

## Архитектура

Проект разделён на независимые слои:

- **Pipelines** – обёртки над конкретными ML‑моделями, реализующие единый интерфейс.
- **Services** – управляют жизненным циклом моделей (загрузка, выгрузка, offloading) и предоставляют асинхронные методы генерации.
- **API-сервер** (FastAPI) – принимает клиентские запросы, создаёт фоновые задачи и возвращает статус/результат.
- **Микросервисы** – при необходимости каждый сервис может быть запущен как независимый процесс со своим HTTP‑интерфейсом и health‑check’ом.
- **Launcher** – единая точка запуска `start.py`, выбирающая конфигурацию (монолит / микросервисы / gateway) в зависимости от параметров и окружения.

Все компоненты взаимодействуют через абстрактные базовые классы (`BaseText2ImageService`, `BaseImage2ShapeService`, `BaseText2ShapeService`), что позволяет легко заменять реализацию: локальную модель на удалённый сервис, одну модель на другую и т. д.

## Требования

- Python 3.10+
- [PyTorch](https://pytorch.org/) (сборка под ваше оборудование)
- Для GPU: NVIDIA CUDA 11.8+
- Рекомендуется 16 ГБ видеопамяти для полного 3D‑пайплайна.
- Дополнительные библиотеки перечислены в `requirements.txt` (FastAPI, aiohttp, trimesh, diffusers, hy3dgen и др.)

## Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-org/arti-generative-services.git
   cd arti-generative-services
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите сервис в монолитном режиме (локальная разработка):**
   ```bash
   python start.py --mode monolith --profile auto
   ```
   Профиль `auto` автоматически определит, какое оборудование доступно, и выберет подходящие модели.

4. **Проверьте работу:**
   ```bash
   curl -X POST http://localhost:8000/generate/2d \
        -H "Content-Type: application/json" \
        -d '{"prompt": "футуристический город", "seed": 42}'
   ```
   Вернёт `{"task_id": "..."}`. Статус задачи:  
   `GET http://localhost:8000/status/2d/{task_id}`.  
   Готовый результат: `GET http://localhost:8000/download/2d/{task_id}`.

   Для 3D:
   ```bash
   curl -X POST http://localhost:8000/generate/3d \
        -H "Content-Type: application/json" \
        -d '{"prompt": "робот-пылесос"}'
   ```

## Конфигурация

Все настройки задаются переменными окружения или аргументами `start.py`.

### Профили

| Профиль | Описание |
|---------|----------|
| `high`  | Мощный GPU (≥10 ГБ VRAM). Используются полноразмерные модели. 3D‑генерация доступна. |
| `low`   | Интегрированная графика / CPU. Только облегчённая 2D‑модель. 3D недоступно локально. |
| `auto`  | Автоопределение: `high` при достаточном объёме видеопамяти, иначе `low`. |

Задать профиль: `PROFILE=high` или `--profile high`.

### Основные переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|------------|------------|------------------------|
| `PROFILE` | Профиль оборудования | `auto` |
| `TEXT2IMAGE_SERVICE_URL` | URL удалённого сервиса генерации изображений (если не задан – локальная модель) | (пусто) |
| `IMAGE2SHAPE_SERVICE_URL` | URL удалённого сервиса генерации 3D | (пусто) |
| `TEXT2IMG_MODEL` | Путь или ID модели текст → изображение для профиля `high` | `PixArt-alpha/PixArt-Sigma-XL-2-1024-MS` |
| `SHAPE_MODEL` | Путь к модели формы (Image → 3D) | `tencent/Hunyuan3D-2mini` |
| `TEX_MODEL` | Путь к модели текстурирования | `tencent/Hunyuan3D-2` |
| `SUBFOLDER` | Подпапка в репозитории модели | `hunyuan3d-dit-v2-0` |

### Аргументы командной строки (`start.py`)

| Аргумент | Описание |
|----------|----------|
| `--mode` | Режим запуска: `monolith`, `split`, `gateway` |
| `--host` | Хост для всех сервисов (по умолчанию `0.0.0.0`) |
| `--port` | Порт API Gateway (по умолчанию `8000`) |
| `--text2image-port` | Порт микросервиса Text2Image (только для `split`) |
| `--image2shape-port` | Порт микросервиса Image2Shape (только для `split`) |
| `--profile` | Профиль (`high`, `low`, `auto`) |
| `--text2image-url` | URL внешнего сервиса (для `gateway`) |
| `--image2shape-url` | URL внешнего сервиса (для `gateway`) |

## Режимы развёртывания

### 1. Монолитный (`monolith`)
Всё в одном процессе – удобно для разработки и тестирования.  
`python start.py --mode monolith`

### 2. Микросервисы на одной машине (`split`)
API Gateway + отдельные процессы Text2Image и Image2Shape.  
Позволяет изолировать компоненты и эффективнее управлять GPU‑памятью.  
`python start.py --mode split`  
Сервисы поднимаются на портах `8001` и `8002`, Gateway – на `8000`.

### 3. Шлюз к удалённым сервисам (`gateway`)
Используется, когда генеративные модели запущены на другой мощной машине.  
`python start.py --mode gateway --text2image-url http://gpu-server:8001 --image2shape-url http://gpu-server:8002`  
API Gateway принимает запросы клиентов и перенаправляет их к указанным сервисам.

## Расширение и замена моделей

### Как добавить новую модель?

Достаточно реализовать один из абстрактных классов в `pipelines/base.py`:

```python
from pipelines.base import BaseText2Image
from PIL import Image

class MyCustomText2Image(BaseText2Image):
    def __init__(self, model_path: str, device: str = "cpu"):
        # загрузка вашей модели
        ...

    def generate(self, prompt: str, **kwargs) -> Image.Image:
        # генерация изображения
        ...
```

Затем зарегистрируйте новый класс в фабрике сервисов (файл `services/__init__.py`) или передайте через переменную окружения.

### Как заменить удалённый сервис своей реализацией?

Если вы развернули собственный микросервис, реализующий те же эндпоинты `/generate` и `/health`, просто укажите его URL в `TEXT2IMAGE_SERVICE_URL` или `IMAGE2SHAPE_SERVICE_URL`. Никаких изменений в коде не требуется – будет использован HTTP‑клиент, соответствующий базовому интерфейсу.

## Примеры использования API

### Генерация изображения

```python
import requests, time

resp = requests.post("http://localhost:8000/generate/2d", json={"prompt": "космический пейзаж"})
task_id = resp.json()["task_id"]

while True:
    status = requests.get(f"http://localhost:8000/status/2d/{task_id}").json()
    if status["status"] == "completed":
        print("Изображение готово:", status["download_url"])
        break
    elif status["status"] == "failed":
        print("Ошибка:", status["error"])
        break
    time.sleep(2)

# Скачать изображение
img_data = requests.get(f"http://localhost:8000{status['download_url']}").content
with open("output.png", "wb") as f:
    f.write(img_data)
```

### Генерация 3D‑модели

Аналогично, но эндпоинт `/generate/3d` и формат результата – GLB.

### Веб‑монитор

Откройте `http://localhost:8000/monitor` – простой дашборд, показывающий текущие задачи и позволяющий скачать готовые файлы.

## Интеграция в ARTi Platform

Данный сервис является частью подсистемы **Forge** платформы ARTi.  
- **Forge** – инструменты художника: создание 3D‑контента из текста или эскизов, генерация текстур.  
- **Lens** – мобильное приложение дополненной реальности для посетителей.  
- **Curat** – панель куратора для организации выставок.

Сгенерированные модель и изображение могут быть сразу опубликованы через API Forge, снабжены метаданными и переданы в Lens для отображения в AR.
